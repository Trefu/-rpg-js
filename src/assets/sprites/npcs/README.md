# Forest NPCs

Generated from the two supplied sprite sheets in
`new-assets/TheForestCharacterPack2_FreeVersion/TheForestCharacterPack2_FreeVersion`.

- `forest-merchant.gif` / `.png`: Character 1, used by the expedition merchant.
- `forest-wanderer.gif` / `.png`: Character 2, prepared for a future role.

The importer preserves all 10 frames, the frame dimensions and animation timings
from each original `.aseprite` file. PNGs are still-image alternatives for reduced motion.
Regenerate with `python scripts/import_new_assets.py` (requires Pillow).
